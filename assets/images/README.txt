Format .jpg, .webp, .png, atau .jpeg semuanya boleh: website otomatis
mencari ekstensi yang ada, jadi HTML tidak perlu diubah.
Tips: ubah ke WebP dan kecilkan sisi terpanjang jadi sekitar 1600px agar cepat dibuka.
